Sätt upp Windows Server:  
Installera servern och konfigurera statisk IP samt lokal DNS (loopback) så att den kan bli en Domänkontrollant (DC).  

Starta installation av Windows Server 2025.  
Välj ISO-fil och påbörja installation:  
Välj ```språk: Engelska (United States)```  
Välj ```tangentbordslayout: Svenska```  

Välj Windows Server version med Desktop Experience:  
*Windows Server 2025 Datacenter Evaluation (Desktop Experience)  
*Standard Evaluation (Desktop Experience)  

Slutför installation med ett starkt admin-lösenord för kontot ```Administrator```.  
Starta om enhet och logga in med ```Administrator```.

```Preferred DNS server: 127.0.0.1```

# Installera AD DS och konfigurera servern som domänkontrollant

## Installera Active Directory Domain Services

1. Öppna **Server Manager** när servern har startat om.
2. Välj **Manage > Add Roles and Features**.
3. Klicka på **Next** tills du kommer till **Server Roles**.
4. Markera **Active Directory Domain Services**. Godkänn de tillhörande administrationsverktygen (**Management Tools**) genom att klicka på **Add Features** i dialogrutan.
5. Kontrollera att **DNS Server** också markeras, om rollen inte läggs till automatiskt i nästa steg.
6. Fortsätt med **Next** och klicka sedan på **Install**. Vänta tills installationen av rollfilerna är färdig.

## Konfigurera servern som domänkontrollant (DC)

1. När installationen är klar klickar du på den gula varningssymbolen högst upp i **Server Manager**. Välj **Promote this server to a domain controller**.

2. Gör följande val i konfigurationsguiden:
   - Välj **Add a new forest**.
   - Under **Root domain name** anger du domännamnet, `sost.local`.

3. På sidan **Domain Controller Options**:
   - Behåll funktionsnivåerna (**Functional Levels**) på högsta tillgängliga nivå, i denna övning **Windows Server 2025** för både skog och domän.
   - Kontrollera att **Domain Name System (DNS) server** och **Global Catalog (GC)** är markerade.
   - Ange ett starkt lösenord för **Directory Services Restore Mode (DSRM)**.

4. Fortsätt genom **DNS Options**, **Additional Options** och **Paths**. NetBIOS-namnet skapas automatiskt, `SOST`. Behåll standardsökvägarna för NTDS-databasen, loggfilerna och SYSVOL.

5. När kontrollen av förutsättningarna (**Prerequisites Check**) har godkänts klickar du på **Install**.

6. När konfigurationen av Active Directory är färdig startar servern om automatiskt.

## Kontrollera konfigurationen

### Kontrollera Active Directory-verktygen

1. Öppna **Server Manager > Tools**.
2. Kontrollera att **Active Directory Users and Computers (ADUC)** och **DNS** finns i menyn och att båda verktygen går att öppna.

### Kontrollera AD och DNS med PowerShell

Öppna **PowerShell** och kör följande kommandon för att kontrollera nätverksinställningarna och domänkontrollantens funktion:

```powershell
# Visa serverns IP-inställningar
Get-NetIPConfiguration

# Kör en utförlig diagnostik av domänkontrollanten
dcdiag /v
```

**Kontrollera konfigurationerna**

- **Kontrollera Active Directory-verktygen:**
  - Gå till **Server Manager > Tools**.
  - Säkerställ att **Active Directory Users and Computers (ADUC)** och **DNS** är tillgängliga och kan öppnas.
- **Kontrollera via Kommandotolken/PowerShell:**

  Starta PowerShell och kör kommandona nedan för att kontrollera hälsan hos AD och DNS:
  ```
  # Granska IP-inställningarna
  Get-NetIPConfiguration

  # Kontrollera Active Directory-tjänsten och DNS-posterna
  dcdiag /v

  ```
- Gå till *Forward Lookup Zones* i **DNS Manager** och säkerställ att din domän (`sost.local`) har skapats och innehåller SRV-poster (`_msdcs`).
