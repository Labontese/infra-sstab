# Driftsättning & Konfiguration: Windows Server 2025
**Projekt:** Driftsättning av Infrastruktur för Skämt & Sido Transport AB  
**Domän:** `sost.local` | **NetBIOS:** `SOST`  
**Roll:** Domänkontrollant (DC) & DNS-server  

---

## 1. Installation av Windows Server 2025

1. Starta den virtuella maskinen med ISO-filen för **Windows Server 2025**.
2. Välj grundläggande språk och inmatningsinställningar:
   - **Language to install:** English (United States)
   - **Time and currency format:** English (United States) eller Swedish (Sweden)
   - **Keyboard or input method:** Swedish
3. Välj version med grafiskt gränssnitt:
   - **Windows Server 2025 Datacenter Evaluation (Desktop Experience)** *(eller Standard Evaluation)*
4. Acceptera licensvillkoren och slutför installationen.
5. Ange ett starkt administratörslösenord för det lokala kontot `Administrator`.
6. Logga in efter omstart.

---

## 2. Nätverkskonfiguration & Datornamn

> **Viktigt:** En domänkontrollant måste ha en statisk IP-adress och peka på sig själv för lokal DNS-uppslagning (loopback).

### 2.1 Statisk IP och DNS
1. Öppna **Run** (`Win + R`), skriv `ncpa.cpl` och tryck **Enter**.
2. Högerklicka på nätverkskortet > **Properties** > markera **Internet Protocol Version 4 (TCP/IPv4)** > **Properties**.
3. Konfigurera nätverket enligt er tilldelade IP-tabell:
   - **IP address:** *(Enligt gruppens IP-tabell)*
   - **Subnet mask:** *(Enligt gruppens IP-tabell)*
   - **Default gateway:** *(Enligt gruppens IP-tabell)*
   - **Preferred DNS server:** `127.0.0.1` *(Loopback – pekar på den lokala DNS-tjänsten)*
   - **Alternate DNS server:** `1.1.1.1` *(Cloudflare publik DNS för extern uppslagning)*

### 2.2 Datornamn, Tidszon och Uppdateringar
1. Öppna **Server Manager** > klicka på **Local Server**.
2. Klicka på datornamnet (**Computer Name**) och byt namn till `SRV-01-DC` enligt [IP-adressplanen](../reference/ip-plan.md).
3. Kontrollera att tidszon (**Time zone**) och klockslag är korrekt inställt.
4. Kör **Windows Update** och installera eventuella kritiska uppdateringar.
5. **Starta om servern** och logga in igen som `Administrator`.

# 3. Installera AD DS och konfigurera servern som domänkontrollant

## Installera Active Directory Domain Services

1. Öppna **Server Manager** när servern har startat om.
2. Välj **Manage > Add Roles and Features**.
3. Klicka på **Next** tills du kommer till **Server Roles**.
4. Markera **Active Directory Domain Services**. Godkänn de tillhörande administrationsverktygen (**Management Tools**) genom att klicka på **Add Features** i dialogrutan.
5. Kontrollera att **DNS Server** också markeras, om rollen inte läggs till automatiskt i nästa steg.
6. Fortsätt med **Next** och klicka sedan på **Install**. Vänta tills installationen av rollfilerna är färdig.

## 4. Konfigurera servern som domänkontrollant (DC)

1. När installationen är klar klickar du på den gula varningssymbolen högst upp i **Server Manager**. Välj **Promote this server to a domain controller**.

2. Gör följande val i konfigurationsguiden:
   - Välj **Add a new forest**.
   - Under **Root domain name** anger du domännamnet, `sost.local`.

3. På sidan **Domain Controller Options**:
   - Behåll funktionsnivåerna (**Functional Levels**) på högsta tillgängliga nivå, i denna övning **Windows Server 2025** för både skog och domän.
   - Kontrollera att **Domain Name System (DNS) server** och **Global Catalog (GC)** är markerade.
   - Ange ett starkt lösenord för **Directory Services Restore Mode (DSRM)**.

4. Fortsätt genom **DNS Options**, **Additional Options** och **Paths**. NetBIOS-namnet skapas automatiskt, `SOST`. Behåll standardsökvägarna för NTDS-databasen, loggfilerna och SYSVOL.

5. När kontrollen av förutsättningarna (**Prerequisites Check**) har godkänts klickar du på **Install**.

6. När konfigurationen av Active Directory är färdig startar servern om automatiskt.

## 5. Kontrollera konfigurationen

### Kontrollera Active Directory- och DNS-verktygen

1. Öppna **Server Manager > Tools**.
2. Kontrollera att **Active Directory Users and Computers (ADUC)** och **DNS** finns i menyn och att båda verktygen går att öppna.
3. I **DNS Manager**: Gå till *Forward Lookup Zones* och säkerställ att din domän (`sost.local`) har skapats och innehåller undermappen `_msdcs` med SRV-poster.

### Kontrollera AD och DNS med PowerShell

Öppna **PowerShell som Administratör** och kör följande kommandon för att verifiera serverns hälsa:

```powershell
# 1. Granska IP-inställningarna
Get-NetIPConfiguration

# 2. Kör en utförlig diagnostik av domänkontrollanten
dcdiag /v
```
