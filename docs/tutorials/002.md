# Windows Server 2025
Sätt upp Windows Server:  
Installera servern och konfigurera statisk IP samt lokal DNS (loopback) så att den kan bli en Domänkontrollant (DC).  

Starta installation av Windows Server 2025.  
Välj ISO-fil och påbörja installation:  
Välj ```språk: Engelska (United States)```  
Välj ```tangentbordslayout: Svenska```  

Välj Windows Server version med Desktop Experience:  
*Windows Server 2025 Datacenter Evaluation (Desktop Experience)  
*Standard Evaluation (Desktop Experience)  

Slutför installation med ett starkt admin-lösenord för kontot ```Administrator```.  
Starta om enhet och logga in med ```Administrator```.  
 
---
Kör ```ncpa.cpl``` genom Run (Win+R) och ange nätverksinställningar för nätverket: ```Internet Protocol Version 4 (TCP/IPv4)```:  

Följ
[IP-tabell](../../docs/reference/ip-plan.md) för Windows Server


Servern behöver peka på sig själv gällande DNS:  
```Preferred DNS server: 127.0.0.1```  
```Alternate DNS server: 1.1.1.1```  

Det är viktigt att kontrollera att IP och DNS är statiska och fasta. AD DS är beroende av att alltid nås till samma IP-address.

---

Ändra namn på Server enligt [IP-tabell](../../docs/reference/ip-plan.md):   
Server Manager > Local Server > Computer Name  

Starta om enhet och logga in med ```Administrator```.

Övrigt:  
Uppdatera Windows Update.  
Kontrollera och ställa in rätt tidszon och klockslag.
