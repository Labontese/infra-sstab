# Dokumentationsmall – Diátaxis

Tom mall för att strukturera dokumentation enligt [Diátaxis](https://diataxis.fr/): fyra mappar för fyra olika behov. Fyll på i respektive mapp när ett konkret ämne ska dokumenteras.

| Mapp | Frågan den svarar på | Exempel |
|---|---|---|
| `tutorials/` | "Hur lär jag mig genom att göra?" | Steg-för-steg-guide som tar en nybörjare från noll till ett konkret resultat |
| `how-to/` | "Hur löser jag den här specifika uppgiften?" | Kort, målinriktad instruktion för en erfaren läsare |
| `reference/` | "Vad finns, exakt?" | Fakta, tabeller, konfigurationsvärden – inget resonemang |
| `explanation/` | "Varför är det byggt så?" | Bakgrund, resonemang, avvägningar |

Varje mapp innehåller en `MALL.md` med rubrikstruktur och instruktioner – döp om och fyll i den när du skriver ett riktigt dokument, eller skapa en ny fil enligt samma mönster.
