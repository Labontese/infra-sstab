# Driftdokumentation – infra-sstab

Dokumentationen är strukturerad enligt [Diátaxis](https://diataxis.fr/): fyra mappar för fyra olika behov.

| Mapp | Frågan den svarar på | Exempel |
|---|---|---|
| `tutorials/` | "Hur lär jag mig genom att göra?" | Skapa och starta din första VM |
| `how-to/` | "Hur löser jag den här specifika uppgiften?" | Kom åt Proxmox hemifrån/bortifrån |
| `reference/` | "Vad finns, exakt?" | Nätverksbryggor, lagringspooler, VM/LXC-inventering |
| `explanation/` | "Varför är det byggt så?" | Åtkomstarkitektur, VMID-struktur |

Branch: `daniel` – Daniels arbetsgren för att dokumentera infrastrukturen. Merga mot `main` när ett avsnitt är klart.
