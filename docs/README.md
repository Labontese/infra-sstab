# Driftdokumentation

Driftdokumentation för skoluppgiften Boiler Room.

Strukturerad enligt [Diátaxis](https://diataxis.fr/): fyra mappar för fyra olika behov.

| Mapp | Frågan den svarar på |
|---|---|
| `tutorials/` | "Hur lär jag mig genom att göra?" |
| `how-to/` | "Hur löser jag den här specifika uppgiften?" |
| `reference/` | "Vad finns, exakt?" |
| `explanation/` | "Varför är det byggt så?" |
